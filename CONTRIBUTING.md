# Contributing to PROJECT NOMAD

Thank you for your interest in community-owned sovereign AI infrastructure.

## Ways to contribute

- Review architecture and threat models.
- Test local inference and offline knowledge retrieval.
- Improve accessibility, localisation and documentation.
- Evaluate hardware, power and network configurations.
- Review privacy, safeguarding and governance proposals.
- Report bugs and propose features through GitHub Issues.

## Contribution process

1. Open an issue before substantial work so the scope can be discussed.
2. Fork the repository and create a focused branch.
3. Make a small, reviewable change.
4. Add or update tests and documentation where applicable.
5. Open a pull request describing motivation, implementation, testing and limitations.

## Safety and privacy

Never commit passwords, API keys, private partner material, personal data, student records, confidential school information or unlicensed datasets. Use synthetic test data. Disclose security vulnerabilities privately to the maintainers rather than in a public issue.

## Licensing

By submitting a contribution, you agree that it is offered under the repository's Apache License 2.0, unless an explicitly agreed alternative applies. Do not contribute material you do not have the rights to submit.
