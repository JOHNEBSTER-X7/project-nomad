# Security Policy

## Reporting a vulnerability

Do not publish exploitable security details in a public issue. Contact the project lead at dragoxprotocol@proton.me with the subject line **PROJECT NOMAD Security Report**. Include affected component, impact, reproduction steps and any suggested mitigation. Do not include real student or other personal data.

## Scope

The project is at an early research and prototype-planning stage. There is no production deployment or service-level security commitment.

## Security expectations

- Never commit secrets, tokens, credentials or private keys.
- Keep dependencies and container images updated.
- Use least-privilege access and secure defaults.
- Review authentication, authorisation and network boundaries.
- Avoid exposing local AI or administrative services directly to the public internet.
- Test backup restoration and incident response before a field pilot.
- Treat all school and learner data as sensitive and minimise its use.
